# Atividade-Individual

# Descrição do projeto
O projeto tem a ideia de ser um aplicativo de notícias sobre o esporte automobilístico como, F1, F2, F3, Nascar, GTR, entre outros.

# Descrição das funcionalidades
mostrando as notícias mais recentes, bem avaliadas, dividias em categorias para o seu gosto especial por qual modalidade o usuário mais gosta. Tendo pesquisas mais quentes (que estão mais conhecidas no momento) e podendo guardar os seus dados como os de usuário e endereço.

# Tecnologia utilizadas
Dart por meio do FlutterFlow, Java.
